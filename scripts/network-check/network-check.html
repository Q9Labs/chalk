What these results mean

OPEN means the WebSocket upgrade succeeded (HTTP 101). The check then closes it deliberately, without sending an access token. Code 1000 is a normal close; 1006 means the browser saw an abnormal close. A timeout means no open within 4.5 seconds.

Browsers do not expose a failed WebSocket’s HTTP status or the network’s reason. A failed Sync socket with working controls narrows the problem; it does not prove an ISP, hostname, QUIC or server fault.

Results stay on this screen. Requests send no call or user identifiers. Normal service access logs may record the request IP and browser.
