# 2026-W26 (2026-06-22 – 2026-06-28)

Condensed from 2 session logs. Originals removed on `chore/docs-scratch-cleanup`;
full text remains in git history.

## API and infrastructure teardown (2026-06-24)

Destroyed the Terraform-managed production infrastructure from GitHub Actions
while the Terraform code still existed, then removed the old `apps/api`,
`infrastructure/terraform`, `infrastructure/whisper-worker`, and
`infrastructure/cloudflare-worker` trees.

- Old prod Terraform managed API EC2/EIP/security group/SSM/ECR, Cloudflare
  DNS/R2 config, Upstash Redis, and a PlanetScale branch role.
- **R2 data was the deliberate carve-out.** The destroy workflow removed R2
  bucket/CORS/lifecycle resources from Terraform state _before_ `terraform
destroy` so the bucket and its data survived.
- The old Cloudflare post-meeting worker was not tracked in Terraform; a
  temporary CI workflow did best-effort cleanup of Cloudflare Worker scripts and
  Queues with `chalk` in the name.

## Go API foundations (2026-06-27)

First intentional pass at the Go API before any endpoints, aligned to
`docs/redesign/north-star.md`: composable hexagonal boundaries, swappable
`MediaPlane`/`SyncEngine` ports, provider details behind adapters, self-host
friendly app tier.

**Toolchain.** `gopls v0.20.0` is the first stable MCP-capable version declaring
`go 1.24.2`; Codex MCP entry `gopls_chalk_api` starts `gopls mcp` from `apps/api`.

**Gate.** `apps/api/scripts/gate.sh` runs version check, non-mutating `gofmt`,
`go mod tidy -diff`, `go test`, `go vet`, pinned `staticcheck ./...` (v0.6.1),
pinned `govulncheck ./...` (v1.1.4), and `go test -race` when `CHALK_API_RACE=1`.
Wired into `scripts/gates/commit.sh`. `apps/api/scripts/format.sh` does the
intentional `gofmt -w`.

**Toolchain policy.** The gate sets
`GOTOOLCHAIN=${CHALK_API_GOTOOLCHAIN:-go1.25.11+auto}` rather than replacing
root-owned `/usr/local/go`. `go.mod` declares `go 1.25.11` because `govulncheck`
found stdlib vulnerabilities in `go1.24.4` and 1.25.11 was the highest fixed
version reported. Do not force `GOTOOLCHAIN=local` unless the system Go is
patched to ≥1.25.11.

**Lifecycle gate.** `apps/api/scripts/smoke-lifecycle.mjs` builds the binary,
measures time to `GET /healthz` = 200, sends `SIGTERM`, measures clean exit.
Budgets default to 3000ms each, overridable via
`CHALK_API_LIFECYCLE_{STARTUP,SHUTDOWN}_BUDGET_MS`. First local run: ~33-39ms
startup, ~2ms shutdown.

**Config.** `apps/api/internal/config` is the env-only boundary
(`CHALK_API_ADDR` `:8080`, `CHALK_DATABASE_URL`, `CHALK_DATABASE_MAX_CONNS` 10,
`CHALK_DATABASE_MIN_CONNS` 0). The binary stays provider-agnostic — environments
inject config; startup never calls a vendor secret manager.

**Database.** `pgxpool` foundation in `internal/postgres`, which owns pool
construction and pinging while `cmd/main.go` opens the DB before serving.
`/healthz` stays process-only; `/readyz` pings Postgres.
`apps/api/scripts/dev-postgres.sh` runs `postgres:18.3-alpine` (matching
PlanetScale's supported Postgres 18 minor) on OrbStack/Docker, data in the named
volume `chalk-postgres` mounted at `/var/lib/postgresql`; `rm` drops the
container, `wipe` drops container and volume.

**Queries and migrations: `sqlc` + `pgx` and `goose`.** `sqlc` pinned to v1.30.0
because v1.31.1 requires Go 1.26 and the module stays on 1.25.11; `goose` pinned
to v3.27.1. Queries in `db/queries`, versioned migrations in `db/migrations`,
generated code into `internal/postgres/db` and never hand-edited. **API startup
does not apply migrations** — `scripts/db-migrate.sh` runs goose explicitly.

**Router.** `chi`, with one public REST version boundary under `/v1`, operational
routes like `/healthz` outside it, mount functions for root composition and small
route groups, and mounted domain HTTP adapters once a domain has enough
routes/middleware/ports to own an inbound adapter. HTTP handlers translate into
application/domain services; they are not the domain layer.
