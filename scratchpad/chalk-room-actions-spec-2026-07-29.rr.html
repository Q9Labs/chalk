D1 · Durable room-wide text

Include acknowledgements, paging, reconnect recovery, retention, and local unread state.

Attachments, edit/delete, typing, durable receipts, and message reactions stay out.

D2 · All clients, browser whiteboard

Web, iOS, and Android include reactions, chat, requests, and moderation.

Browser Excalidraw is included. Native mobile whiteboard is deferred.

D3 · Retention values

Recommend: seven days after Session end; never clean active Sessions; reject writes at end.

Alternatives: one day or thirty days.

D4 · Transport

Recommend: a separate collab-v1 socket owned by the same Elixir SyncEngine.

Alternative: Sync v4 or a separate negotiated subprotocol. Strict Sync v3 remains unchanged.

 D5 · Excalidraw images — Recommend: staged, participant-authenticated upload with server verification and cleanup. Alternative: disable the image tool and reject image elements.
