Existing store

Diagnostics: one row per Episode, explicit environment and seven-day expiry.

Events: append-only evidence with a contiguous, commit-ordered cursor per Diagnostic.

Operations, checkpoints, branches, and Issues: replayable projections with leases and offsets.

References: approved raw or HMAC ID classes resolve safely to a focus.

Episode Diagnostic store

Normal traces stay bounded in Tempo, logs stay in Loki, and metrics stay in Prometheus. The Episode store links them without copying every raw signal.

Complete means complete state transitions, not captured content

Always recorded

Action kind, safe state, timing, attempts, checkpoints, bounded error class, source, release, visibility, and approved identifiers.

Never recorded

Chat text, attachment bodies, display names, tokens, raw SDP or ICE data, media, whiteboard content, webhook bodies, or arbitrary exceptions.

Diagnostic failure cannot block a product action. Queue overflow, exporter loss, storage failure, and stream lag become telemetry gaps instead.

Production starts no route, append credential, observer, exporter, projector, export job, retention worker, resolver, or operator UI. This spec authorizes no production change.

Episode end freezes the run, then the epilogue finishes

  1. Live EpisodeParticipants, actions, media, Sync, Issues, and recovery stream continuously
  2. Episode endedThe main run becomes immutable
  3. EpiloguePre-authorized branches stay live without mutating the ended Episode or committed artifacts
  4. CompleteEvery branch succeeds, fails, cancels, or times out within 24 hours; retention begins
  5. ExpiredBounded cleanup deletes the complete diagnostic and records safe health signals

Five gated phases keep shared contracts ahead of parallel lanes

  1. P0 · Contract freezeOne shared package: schemas, action set, ID registry, redaction, fixtures
  2. P1 · FoundationsAPI and SDK foundations plus shared new-design-system tokens before the polished UI shell
  3. P2 · Complete lanesProjection, checkpoints, polished debugger views, visual states, and agent resolver
  4. P3 · IntegrationAuthoritative Episode identity, correlations, every action, epilogue
  5. P4 · ProofBrowser, silent stall, failure isolation, security, 8h/100/1M capacity
  6. P5 · HandoffDocs, gates, bounded review, scoped commit; no push or deploy

The orchestrator owns every contract gate and integration seam. Parallel lanes do not discover or redefine shared shapes independently.
