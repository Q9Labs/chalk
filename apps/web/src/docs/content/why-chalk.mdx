## Video calls inside your product

Chalk puts video calls in your app, with chat and a shared whiteboard that are still there after the call ends. Start with the [quickstart](/docs/quickstart): it puts a working call on screen in a few minutes.

### Spaces and Episodes

Take a team's weekly standup. The standup itself is a **Space**: one link that keeps the same members, chat and whiteboard from week to week. Each Monday's call is an **Episode**: it starts when the first person joins, records who was there and what happened, and freezes when the call ends.

People always join the Space, and Chalk starts the Episode for them. A Space has at most one live Episode, so a link always leads to the call that is happening now, and its history stays in order.

### One client, several UI choices

The framework-agnostic `SpaceClient` owns access, recovery, state, and feature commands. React and React Native bind to the same `SpaceSnapshot`, so a custom surface and the turnkey UI share one behavior contract.

### Built for product boundaries

Chalk keeps server work and client work separate. Your backend mints the opaque `AccessGrant`; the client refreshes it when needed. Capabilities decide what an identity may do now, while customer-defined Roles group those capabilities. Webhooks and the public API make durable operations visible outside the live surface.

The result is a collaboration layer that can sit inside an existing product without taking ownership of identity, navigation, or your application's data model.
