## Turnkey UI is the shortest path to a Space

`<Chalk />` owns joining, the live surface, feature panels, and client wiring. Set feature flags for the pieces your product needs, then place the component inside a sized parent.

```tsx
<Chalk
  client={spaceClient}
  features={{
    participants: true,
    admission: true,
    chat: true,
    screenShare: true,
    whiteboard: true,
    reactions: true,
    handRaise: true,
  }}
  layout="focus"
/>
```

Web and React Native share the `chat`, `participants`, `admission`, `screenShare`, `whiteboard`, `reactions`, and `handRaise` feature flags. Web also exposes `recording` and `sounds`; React Native also exposes `info` and `settings`. The `sounds` flag controls join, leave, message, hand-raise, and reaction cues.

### Theme the boundary

The `theme` prop is the styling door. Web supports `colorScheme: "light" | "dark"` (dark by default), an accent, and typed token overrides. Use `onColorSchemeChange` to persist the Light/Dark choice. Native maps the same token names to platform styles.

```tsx
<Chalk
  client={spaceClient}
  theme={{
    colorScheme: "dark",
    accent: "#4b9bb8",
    tokens: { canvas: "#152127", surface: "#1d2b31" },
  }}
/>
```

Use the standalone `Entrance` when your product needs a separate entry step. Use [Custom UI](/docs/custom-ui) when the turnkey layout does not fit.
