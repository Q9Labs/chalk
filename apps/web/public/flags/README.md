# Language flags

Flag drawings for the transcript language picker, copied from [country-flag-icons](https://gitlab.com/catamphetamine/country-flag-icons) 1.6.20 (3x2). Flags are public-domain artwork; the package is MIT licensed. `apps/web/src/components/dashboard/transcript-languages.ts` maps each language to one file here, and a test fails when a mapped file is missing.
