Search scope: `apps/web`, `sdks/typescript/{client,react}`, `packages/{ui,assets,whiteboard}` and the pinned runtime dependencies. Local CSS imports resolve through Vite. No external CSS `@import` or network dynamic import remains in application sources. Excalidraw's fallback URL remains inside the vendor bundle, but successfully loaded local fonts avoid the fallback; browser tests check actual requests and successful font loading.

`packages/assets/src/index.ts` declares `assets.chalkmeet.com` sound URLs. Those belong to Chalk, are not third parties, and the current React call sound player synthesizes its cues. API/sync endpoints are Chalk services; SFU/TURN addresses and user-supplied chat attachments are service or user content, not font/script/CDN assets. Outgoing GitHub, identity-provider and legal links do not load on page render. The embedded/native renderer already copies local assets and has an offline CSP.

The build copies static whiteboard assets from pinned installed packages without contacting a CDN. These files stay outside the JavaScript bundle and load only when used. Versioned vendor paths have a one-year immutable cache; editable font stylesheets and their hashed font files revalidate after one day. Each site font's OFL licence ships beside its font files, and the MathJax Apache licence ships with the runtime.

The web app configures local asset paths through `@q9labsai/chalk-whiteboard/assets` before loading a board. External SDK hosts retain their existing CDN defaults; hosts choosing self-hosting can call `configureWhiteboardAssets` with their own Excalidraw CSS and MathJax base paths. A custom `excalidrawCssPath` also selects the adjacent Excalidraw font directory, including in the native `file://` renderer. Both Vite configurations copy assets at startup, so a clean checkout works with `pnpm dev` without a prior build.
