Search scope: `apps/web`, `sdks/typescript/{client,react}`, `packages/{ui,assets,whiteboard}` and the pinned runtime dependencies. Local CSS imports resolve through Vite. No external CSS `@import` or network dynamic import remains in application sources. The web-only `scripts/self-hosted-excalidraw.ts` Vite transform removes Excalidraw's external font retry in both development and production, and fails the build if that pinned code changes. Its dependency stays outside development prebundling so the same transform handles both modes. A browser regression forces a local Virgil font to return 404 during SVG export and rejects any external fallback request. Published SDK builds retain their upstream CDN defaults.

`packages/assets/src/index.ts` declares `assets.chalkmeet.com` sound URLs. Those belong to Chalk, are not third parties, and the current React call sound player synthesizes its cues. API/sync endpoints are Chalk services; SFU/TURN addresses and user-supplied chat attachments are service or user content, not font/script/CDN assets. Outgoing GitHub, identity-provider and legal links do not load on page render. The embedded/native renderer already copies local assets and has an offline CSP.

The build copies static whiteboard assets from pinned installed packages without contacting a CDN. These files stay outside the JavaScript bundle and load only when used. Versioned vendor paths have a one-year immutable cache; editable font stylesheets and their hashed font files revalidate after one day. Each site font's OFL licence ships beside its font files, and the MathJax Apache licence ships with the runtime.

The web app configures local asset paths through `@q9labsai/chalk-whiteboard/assets` in a bootstrap module imported before the SDK. Configuration sets Excalidraw's font base synchronously, before static SDK imports can initialize its font faces. External SDK hosts retain their existing CDN defaults. Self-hosting hosts must call `configureWhiteboardAssets` in a bootstrap module imported before the SDK, with their Excalidraw CSS and MathJax base paths. The existing `excalidrawCssPath` prop overrides the stylesheet; passing it alone cannot initialize fonts before eager SDK imports. The embedded renderer retains its own local font configuration and resolves relative paths against its `file://` document URL. Both Vite configurations copy assets at startup, so a clean checkout works with `pnpm dev` without a prior build. The copy step verifies installed package versions against the same constants used by the web URLs and fails when an upgrade would reuse an immutable asset URL.
