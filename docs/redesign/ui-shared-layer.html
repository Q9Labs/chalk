Chalk shared UI layer

One shared layer for every Chalk screen

Dark only. Each section shows the same pieces at Desktop 1440, iPad 820 and Mobile 390. Frames reflow by their own width, so all three render on one page. Use the tabs to look at one size at a time, and Fit to width to shrink a frame to the window.

1

Foundations

Color roles, surface levels, radius, spacing, type and icons. Every other layer reads these values and adds none. The call details popup and the call link popup now share one popup surface.

2

Buttons and controls

One kit: round and pill shapes, one hover and press rule. Toolbars, zoom pills and people pills share one shell, and a toolbar has at most one overflow menu.

3

Avatars

A flat, round avatar with initials is the default. A photo is cropped toward the face, and the avatar box never shrinks, so a face is not clipped in a toast, a row or a stack.

4

Popups

Four popups, one surface. A dialog is centered over the scrim, and becomes a bottom sheet on a phone. A popover or menu anchors to its trigger. A tooltip is an inverted pill.

5

Toasts and alerts

One toast system with one position per breakpoint. Every variant shares the popup surface and anatomy: a 20px icon or 28px avatar, one sentence, at most two action pills, and a close button on errors.

6

Empty states

One centered pattern: icon, title, one line of help, one action. The same stack and spacing in a page, a panel or a sheet.

7

Status and feedback

State that the call itself reports: a reconnecting banner, loading placeholders, waiting indicators and badges. None of it moves the layout.

8

Forms

Fields are 44px pills on the raised fill with a 40% white border, so the boundary holds 3:1 on every surface. Focus, error and disabled change the border and nothing else.

9

Rows and lists

Rows are 52px for people and 64px for calls, with one anatomy: avatar, name and meta, status icons, one trailing action. Hosts see the waiting section first.

10

Time format

12-hour AM and PM is the default everywhere a time is shown. The same instant reads the same way in chat, in the transcript and in the call list, and differs only in precision.

11

Whiteboard pieces

The board uses the same tokens, shells and menus as the call. Only the canvas and the sticky note colors are new, and both live in the board tokens.

12

Layout stability

A control that only some people get has a reserved slot, so the controls around it stay where they are. Badges and state changes happen inside a control and never change its size.

13

QR code card

A scannable code for the call link. It is the one place that uses pure white, because a scanner needs a bright margin all the way round.

Review notes

Where the values come from

  • apps/web/src/styles/tokens.css holds the old light set, so it is not the source here. Colors, radii, spacing, type and shadows come from the dark tokens in design.md and packages/ui/src/styles/index.css, which agree with each other. Board and note colors come from BoardStyles.tsx and board-model.ts.
  • The mobile SDK mockups are light, so only their shapes were used, never their colors.

Values that are new

  • Avatar sizes large 44 and extra large 64. design.md stops at the size used in rows.
  • QR code box of 132px: a 4px module, 25 modules and a 4-module quiet zone, so every module lands on a whole pixel.
  • Left padding of 10px in a toast that holds an avatar, so the circle is never cut.
  • Pulse duration of 1.6s on the waiting spinner.
  • Placeholder portrait colors in the avatar crop demo. They stand in for a real photo.
  • Empty state copy and the Admit label, which design.md calls "Let in".
  • Heights of the mock call stage, used only to show a toast in place.
  • Touch sizes from 1000px down: an iPad gets 44px targets with the desktop layout.
  • The host-only slot sits after Fullscreen, not between Board and Fullscreen as design.md orders Record.

Calls to confirm

  • The call details popup, the call ready card and the phone sheet now share one popup surface: popover fill, line-strong border and the pop shadow. Toasts move to that surface as well.
  • Sticky notes keep the 4px radius from design.md, so they read as paper.
  • The toast code is in toast-stack/ToastStack.tsx. There is no ClassicToastStack file in this tree.
  • The reserved slot for host-only buttons is a design choice with a visible cost: a guest sees a wider gap before Leave. Moving the slot back between Board and Fullscreen is a one-line change.
