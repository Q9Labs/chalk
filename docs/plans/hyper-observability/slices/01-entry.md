# Slice 01: Entry: dashboard, invite, admission, prejoin, embed and boot

This slice proves that every way into a call either reaches an admitted Participant or leaves a named, attributed reason: a Space page that never boots, an app that boots but never shows its first screen or crashes before the call UI mounts, an embed whose host page blocks Chalk, an invite refused against its own rows, a knock nobody saw, an approval the Guest never collected, devices refused at prejoin, and a dashboard request that failed. SWE-2 builds it, and it owns the prefixes `boot.` `embed.` `invite.` `admission.` `prejoin.` `dashboard.`. It writes against C1 (IDs and envelope: `cs_` minted at boot before auth, `dev_` with `dev_ephemeral`, `formatHandle`, trail headers), C2 (`ProofBundle`, the three verdict fields, three-state values), C3 (delivery, `evidence_gap`, watermarks, the credential-free first-party ingest path) and C4 (compact CLI). It consumes slice 14's edge feed and hands off to slice 2 at the media connection. Code facts are at b3dc1d3afa.

## 1. Scope

The slice starts at the first byte of a Space page, an embed host page or a dashboard page. It ends when the SDK holds an admitted Participant and starts the media connection. Files the builder changes:

- **Boot:** `apps/web/src/routes/__root.tsx`, only `reloadAfterChunkLoadFailure` in `apps/web/src/lib/chunkReload.ts` (`:44-50`; slice 9 owns `PageFailure`, `announce` and the two listeners in that file), and a `apps/web/src/lib/boot-beacon.ts (new)`. That file exports an inline ES5 `BOOT_BEACON_SCRIPT`, rendered next to the theme script at `apps/web/src/routes/__root.tsx:50`, and `sendEntryEvent`. The beacon mints `cs_` and `dev_` and records `framed` (`window.top !== window.self`), `policy_camera` and `policy_microphone` (from `document.permissionsPolicy` or `document.featurePolicy` `allowsFeature`, else `unavailable(no_api)`), `visibility`, storage state and the build ID. It also emits `boot.visible` once on the first `visibilitychange` to visible, and `boot.pagehide` with `app_shown` (true once `boot.app` was shown) on `pagehide`. In `apps/web/src/routes/__root.tsx` the slice also adds the root route's `errorComponent` and `onCatch` to `createRootRoute` (`:12`).
- **Public entrance:** `apps/web/src/components/space/SpacePage.tsx`, `apps/web/src/components/space/entrance-machine.ts` and `apps/web/src/components/space/entry-failure.ts`, and `apps/web/src/lib/chalk-access.ts`, whose `createPublicInviteClient` (`:21-23`) sends C1 trail headers.
- **Prejoin:** `sdks/typescript/react/src/pre-join/usePreJoinDevices.ts` and `apps/web/src/components/space/pre-join/PreJoin.tsx` (including the dev-only fault in section 6, scenario 10).
- **Embed:** `sdks/typescript/react/src/components/chalk/Chalk.tsx`; its in-repo host is `apps/web/src/components/dashboard/OwnerCall.tsx` (read only).
- **API:** `apps/api/internal/publicinvites/service.go`, `apps/api/internal/publicinvites/admission_telemetry.go`, `apps/api/internal/httpapi/public_invites.go`, `apps/api/internal/adapters/postgres/public_episode_admission.go`.
- **Host and dashboard:** `sdks/typescript/react/src/components/admission-panel/KnockNotice.tsx`, and `apps/web/src/components/dashboard/AdmissionKnocks.tsx` and `apps/web/src/components/dashboard/CallPage.tsx`, `apps/web/server/application.ts` and `apps/web/server/session.ts`.
- **Checker and proof:** `scripts/diagnose-call/entry.mjs (new)` (`entryFindingsOf`), `scripts/diagnose-call/scenarios-entry.mjs (new)`, `scripts/diagnose-call/entry.test.mjs (new)`, and `entrySql` in `scripts/diagnose-call/database.mjs`. Thresholds go under an `entry` key in `infrastructure/observability/production-alerts/call-verdict.json`: `boot_app_ms 20000`, `chunk_followup_ms 10000`, `call_ui_ms 20000`, `never_ran_min_visits 20`, `never_ran_window_ms 900000`, `embed_auth_ms 60000`, `embed_window_ms 300000`, `knock_shown_ms 10000`, `knock_seen_ms 5000`, `host_visible_ms 30000`, `poll_before_completed_ms 10000`, `unreadable_min_visitors 3`, `unreadable_window_ms 900000`. The e2e journeys go in a `tests/entry.e2e.ts (new)`, added to the `tests` list in `e2e.config.ts`.

Pre-admission and dashboard client events go through C3's credential-free first-party path, written here as `ENTRY_PATH`, with `sendBeacon` and a `fetch` keepalive fallback. They can't use the SDK outbox, which waits for a credential that a pre-admission page never gets (`sdks/typescript/client/src/telemetry/outbox.ts:196-200`). Native mobile entry gets the api and db rules only, at `partial(client)`; the React Native frame is out of scope.

## 2. Symptom catalogue

## 4. Rule conditions

Missing data never yields healthy. Each rule returns `broken`, `expected` or a gap with its coverage string, and healthy comes only from the sealed `ProofBundle` (C2). A rule reads only the sources named for it here. A source that is `unavailable` gives the named gap, never a pass. Local and Orb stacks have no Cloudflare, so `edge` is `unavailable(no_cloudflare)` there and every rule that reads edge prints `partial(edge)`.

- **`boot.never_ran`** (day scope; reads edge, client). BROKEN: a 15-minute window holds at least 20 edge `200 text/html` documents for `/:a-:b-:c` or `/space/*` (the `_headers` patterns in `apps/web/public/_headers`) to user agents not matching `WhatsApp|facebookexternalhit|Slackbot|TelegramBot|Twitterbot|LinkedInBot|Discordbot|Googlebot|bingbot|Applebot|HeadlessChrome`, with 0 `boot.started` for those paths, at least one `boot.started` for those paths in the previous 24 h, and a `boot.started` of the same build from any path after the window end. EXPECTED: none. Gap: no edge feed gives `partial(edge)`; no `boot.started` of that build after the window gives `partial(client)`. A ratio above zero is never a finding.
- **`boot.app_failed`** (reads client). The clock starts at `boot.started` when `visibility=visible`, else at `boot.visible`; a page never visible is `not_applicable`. BROKEN, any of the following, where (b), (c) and (e) count only what happened before `entry.load_call_ui` ended `ok` on that `cs_` (later ones are slice 8's `render_cause=chunk_reload` reload and slice 9's codes): (a) no `boot.app` shown within 20 s, and a `boot.pagehide` with `app_shown=false` came 20 s or more after the clock start; (b) `boot.chunk_failed` with `reloaded=false`; (c) `boot.chunk_failed` with `reloaded=true` and no new `cs_` on the same persistent `dev_` within 10 s; (d) `entry.load_call_ui` with no terminal within 20 s, or ending `error` with a code other than `chunk_load` (chunk failures are judged by b and c); (e) `hop=client_render`: a `boot.render_failed` or a shown `boot.error_page` on any route, also on a page never visible, with `module` from `route_id` (`web.entrance` under `/_space`, `web.dashboard` under `/dashboard`, else `web.boot`, which also covers a surface whose fact never arrived). When (e) holds, (a) adds no second finding for that page. EXPECTED: `reloaded=true` and a new `cs_` on the same `dev_` within 10 s; that new page is judged on its own. EXPECTED is never (e). Gap: case (a) without any `boot.pagehide`, case (c) on a `dev_ephemeral`, (e) with a `boot.error_page` but no `boot.render_failed` within 5 s, or a client `evidence_gap` in the window gives `partial(client)`; a root catch is never dropped because its partner fact is missing.
- **`embed.blocked`** (reads api, sync). A grant is unused when its Participant has no `sync.websocket.authenticated` whose `participant_id_hash` equals the hash computed exactly as `apps/sync/lib/chalk_sync/transport/socket_context.ex:29-30` computes it from the canonical Participant ID (never from the `pt_` handle), and no api `http.request` on a route naming that Participant other than the grant itself, within 60 s of issue. BROKEN: at least 2 unused grants in one Tenant within 5 min; the finding names the latest grant's `pt_`. EXPECTED: every unused grant's Participant was removed, or its Episode ended, by a tenant-credential request within 60 s of issue. Gap: missing 2xx api logs give `partial(api)`; a sync watermark short of issue plus 60 s gives `partial(sync)`. One unused grant alone is no finding.
- **`invite.refused`** (reads api, db). Reason codes and their return sites are in section 5; they stay server-side, and the client never receives one. The decision is joined to the client by C1 trail headers. A row "at the decision" means the current row when its `state_epoch` equals the decision's input; otherwise the rule gives `partial(db)`. BROKEN: `disabled` while the row at the decision has `enabled=true`, or `disabled_at` null or later than the decision; `generation_mismatch` always, because rotation replaces the handle (`apps/api/db/queries/public_invites.sql:77-83`), so a matching handle with another generation has no legitimate cause; `invalid_row` and `space_mismatch` always; `space_archived` while `archived_at` is null and `spaces.updated_at` precedes the decision; `members_only` while the decision carried a `usr_` with a `memberships` row for that Tenant created before the decision; `arrival_mismatch` unless the arrival's `invite_generation` is lower than the invite's `generation` and `rotated_at` is after the arrival's `created_at`. EXPECTED: `disabled` with `enabled=false` and `disabled_at` before the decision; `space_archived` with `archived_at` before the decision; `members_only` with no `usr_`, or no such `memberships` row; `arrival_mismatch` with the rotation above. Gap: `not_found` is always `partial(api.invite_code)`, because the code is a credential that is never logged. An old link after a rotation lands here, not in `generation_mismatch`.
- **`admission.unanswered`** (reads db, sync, client, edge). The window runs from `requested_at` to `expires_at` (5 min, `apps/api/internal/publicinvites/types.go:58`). A host is positioned when either (1) a Participant in the Episode has `manageAdmission` in `capabilities`, `status='active'`, `joined_at` at or before `requested_at`, a `sync.websocket.authenticated` before `requested_at`, and stays active for 30 s of the window; or (2) a Dashboard Account of the Tenant had `dashboard.call_page` shown and visible for that Space for 30 s of the window, or edge shows its `call-status` reads for that Space at least every 10 s across 30 s of the window. BROKEN: the request expired or stayed pending, a host was positioned, and no knock surface for that request was shown to that host within 10 s; or an `admission.decide` op for that request ended `error`, or ended `ok` with no `decided_at` (db) within 5 s. EXPECTED: no host was positioned, proven by db and sync showing no such Participant and edge showing no `call-status` reads for that Space in the window; or a knock surface was shown to a host for at least 5 s and no `admission.decide` op began. Gap: a positioned host's client watermark short of the window gives `partial(client)`; the no-host case without edge gives `partial(edge)` and never `expected`.
- **`admission.not_collected`** (reads db, api, client). Population: arrivals with `terminal_reason='admission_not_collected'`; the sweeper only takes them once `expires_at` has passed and `completed_at` is 1 minute old (`apps/api/db/queries/sync_lifecycle.sql:800`). EXPECTED: an `entry.pagehide` from the Guest's `cs_` with `phase=waiting` before `completed_at`, and no `public.status` from that arrival after it. BROKEN: no such pagehide, and either the arrival's `public.status` polls continued to within 10 s before `completed_at` with none after it, or they stopped earlier. Gap: an api watermark short of `completed_at` plus 60 s gives `partial(api)`; polls that stopped earlier with no client tail give `broken` with `partial(client)`.
- **`prejoin.devices_blocked`** (reads client). BROKEN: (1) `hop=host_permissions_policy`: `boot.started` has `framed=true` and `policy_camera=false` or `policy_microphone=false`, and `prejoin_access` reaches `blocked` by any trigger; (2) `hop=os_permission`: `prejoin_access` reaches `blocked` by `preview_open` with `error_name=NotAllowedError` while the last `permission_query` read `granted`. EXPECTED: `requesting` to `blocked` on a page whose policy allows both devices (the visitor refused the prompt), or `checking` to `blocked` by `permission_query` on a page with `framed=false` whose policy allows both (an earlier refusal the browser kept). Gap: policy fields `unavailable(no_api)` on a framed page give `partial(client)`.
- **`prejoin.preview_failed`** (reads client). BROKEN: a `prejoin.device_error` whose `error_name` is not `NotAllowedError`, `SecurityError`, `NotFoundError` or `OverconstrainedError` (the denied and missing sets at `sdks/typescript/react/src/pre-join/usePreJoinDevices.ts:289-290`). EXPECTED: none. Gap: a client `evidence_gap` gives `partial(client)`.
- **`dashboard.request_failed`** (reads edge, api). BROKEN: any `/dashboard-api/*` response of 500 or more (`hop=dashboard_upstream` when `upstream_status` is 500 or more, else `hop=dashboard_function`); or 401 with `auth_result=unreadable` for at least 3 distinct `cs_` within 15 min (`hop=dashboard_auth`). EXPECTED: 401 with `auth_result=expired` or `missing`. Fewer than 3 unreadable visitors is no finding. Gap: no edge feed gives `partial(edge)`.

## 7. Out of scope and traps

- **Neighbour slices.** `join.no_media`, listen-only and the SFU `admission_refused` kind already in `scripts/diagnose-call/rules.mjs:256` are slice 2's; don't reuse that name. `rejoin.refused` is slice 8's; access renewal and reconnect are slice 7's. A tenant backend whose `getAccess` throws, and API-key errors, are slice 12's: `embed.blocked` needs a grant that was issued. Crashes after the call UI mounted are slice 9's `page.` codes. A render crash on the entrance or prejoin page before the call UI mounts is this slice's `boot.app_failed` case (e); a native crash before JS runs is slice 9's `app.crashed_at_launch`. A camera failing inside the call is slice 4's. The edge feed is slice 14's, and it ships 5-minute rollups only (`edge.http_rollup`), which `boot.never_ran` reads. The per-request edge rows that `admission.unanswered` (call-status reads) and `dashboard.request_failed` (Pages function logs) read have no owner yet, so those rules print `partial(edge)` in production too until the lead assigns them.
- **Foundation contracts and production.** Don't edit C1 to C4 code, the registry shape, or the Pages project `chalk` (`scripts/deploy/deploy-web-release.mjs:23`). The `_headers` change in fault 2 lives on a throwaway branch only.
- **The invite code is a credential.** Never log it or put it in a fact, and never send a refusal reason to the client. The CSP fact keeps origins and directives, never full URLs.
- **A status is not a reason.** `ErrInviteUnavailable` is one error for eight causes; a 404 or 410 in the client says nothing about which. Logging the API's status in the client and calling it a second witness is wrong; so is counting `http.request` and `public_invite.request` as two, or `public_invite.admission` and its db row.
- **A render or a Promise is not proof.** `CallLimbo` rendering doesn't prove the visitor saw it, so surfaces go through `<ObservedSurface>`. A resolved `getAccess` doesn't prove the embed connected, and `admission.decide` ending `ok` doesn't prove a decision: `decided_at` does.
- **Don't treat `participants.status='active'` as proof of a connection.** Sync activates a Participant in SQL (`apps/sync/lib/chalk_sync/stateholder/postgres/sql/lifecycle.ex:174-177`); a host also needs its sync authentication.
- **Empty is not healthy.** A query that returns no `boot.started`, no knock surface or no edge rows proves an absence only when that source's watermark covers the window; otherwise it's the gap section 4 names. A rotated link refused as `not_found` is a gap, not `expected`.
- **No blanket wrapping.** Add the kernel calls in section 5 and nowhere else: no `op` around every fetch, no global `getUserMedia` or `fetch` proxy, no timer wrapping. Keep existing hashes (`participant_id_hash`) and add no redaction; C1 owns privacy.
