# Recorder control endpoint

Reserved a stable address for the former persistent recorder controller.
The host was removed on 2026-11-15 (PR #1432); its allocation was released and
this stack was never seeded/deployed into Alchemy. The old state is stale.

This is retirement inventory, not an unfinished Nightly deployment. The entry
refuses deploy. Do not reseed or recreate it. `config.ts` documents the typed
`{instance_id}` input through `CHALK_INFRA_INPUTS`; old physical names and IDs
remain only for historical comparison. See [retirement](../migration/README.md).
